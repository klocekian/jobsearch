# Workspace icons

This subset of Tabler outline icons comes from [IconStack](https://iconstack.lovable.app/api), downloaded from its [static Tabler SVG catalog](https://iconstack.lovable.app/api/svg/tabler.json).

The original geometry is rendered as React SVG elements, inherits `currentColor`, and uses a 1.75px stroke for the compact workspace. The selected shortlist star fills the same outline. Only the icons used by the app are bundled; no remote icon requests are made at runtime.

Tabler Icons are by Paweł Kuna, distributed under the included MIT license. Upstream: https://github.com/tabler/tabler-icons.
